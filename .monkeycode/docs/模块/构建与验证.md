# 构建与验证（`tools/`、`test/`）

生成 `build/`、校验 `dist/`、无窗口/POSIX 回归。

## 结构

```
tools/build-all.bat          # Windows：shim + tpc 后端
tools/build-launcher.sh      # launcher + tiny_client.h
tools/verify-bundle.py
tools/e2e/                   # 截图/点窗口（ctypes）
test/posix/                  # host probe、tier、launch-mode、stderr
gui/php/test/smoke.php
```

## 关键文件

| 文件 | 目的 |
|---|---|
| `build-all.bat` | `tpc src/backend.php -o build/app.exe` 等 |
| `verify-bundle.py` | launcher subsystem、捆绑 launcher、DLL 集合 |
| `smoke.php` | 协议与沙箱，不启动窗口 |

## 依赖

tpc、MSVC、g++、python3、（POSIX）bash。

## 规范

- `experiments/` 不参与构建。
- Windows 日常用 `composer test`，不要假设有 bash。
