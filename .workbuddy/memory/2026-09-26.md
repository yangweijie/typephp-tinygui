## 套件按"分发地"重验（同 session 收尾）

- 规矩：**kit 资产只有在它被分发到的位置（技能目录）跑起来才算验过**。in-tree 全绿 → 技能目录跑出
  `TIER1_RC=1`、`STDERR_RC=1`。修好三个真 bug + 一条假通过断言：
  1. `$WORK/app.sock` 在技能目录下恰好 108B = `sun_path` 上限 → `typephp_default_work`（standalone 用
     短临时 scratch）+ `typephp_socket_path`（超长则挪 `/tmp/tpkit.*`，`EXIT` trap 清理）。
  2. `all.sh` 编 `host_probe` 前没有 `mkdir -p "$WORK"`。
  3. "求默认值"的函数无视显式 `WORK=` → 一次 standalone 留下 9 个空临时目录；现 `WORK` 立即短路。
  4. launch 档断言写死 `$WORK/app.sock`，而端点名由入口自取（超长回退 `/tmp/tinyjs-typephp-<pid>.sock`）
     → 分发侧**无条件通过**。改为从 shim 日志读回 `transport=unix-socket pipe=…`。
- 结果：in-tree 与 standalone 都 **51 PASS / 0 FAIL / ALL TIERS OK**；临时目录 0 / 恰好 1。
- 同步纪律：kit 的 standalone 运行不写自己的目录，所以"同步进技能后 `diff -rq` 两边"永远干净。

## 环境备忘（本机）

- POSIX 套件必须用 Cygwin 的 bash：`/d/cygwin64/bin/bash -lc 'cd /cygdrive/d/git/php/typephp-gui/test/posix && bash all.sh'`。
  Git Bash 的 `uname -s` 是 `MINGW64_*`，脚本会直接拒绝（exit 2）。
- Cygwin 的 `/tmp` = `C:\cygwin64\tmp`，从 Git Bash 读要走 `/d/cygwin64/tmp/...`。
- standalone 跑 tier2 需要显式 `BACKEND_PHP=/cygdrive/d/git/php/typephp-gui/src/backend.php`（kit 旁边没有
  `backend.php`，缺省会 SKIP + exit 2，这是设计如此）。
